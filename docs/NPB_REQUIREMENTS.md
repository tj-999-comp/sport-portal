# NPBページ 要件定義

## 1. 文書情報

- 対象: スポーツポータルのNPBページ
- 対象シーズン: 2026年
- 作成日: 2026-09-20
- 親Issue: [#46 NPBページ追加（2026年シーズン）](https://github.com/tj-999-comp/sport-portal/issues/46)
- 要件の基準: 既存のJリーグ版のページ・運用ルール

## 2. 目的

ポータルトップからNPBページへ移動し、2026年シーズンの試合予定・確定結果、セ・パ両リーグの順位・対戦成績、およびポストシーズンの試合予定・結果を確認できるようにする。

## 3. 対象範囲

### 対象

- 2026年セ・パ公式戦の日程・結果
- セ・リーグ／パ・リーグの順位表
- セ・パそれぞれのレギュラーシーズン対戦成績（星取表）
- 2026年クライマックスシリーズ（CS）のトーナメントと各試合の予定・結果
- 2026年日本シリーズのトーナメントと各試合の予定・結果
- NPBデータの自動取得、画面からの手動更新、更新状態・最終更新日時の表示
- ポータルトップからNPBページへの導線
- Bリーグ・NBAの遷移先ページ（本文は「作成途中です」）

### 対象外

- 試合中のライブ速報、現在スコア、得点イベント
- 選手情報、試合詳細ページ、独自の順位決定・勝ち上がり予測
- Bリーグ・NBAの試合・順位データ
- 更新履歴や過去時点の順位保存
- 独自の利用者登録・管理画面

## 4. 共通ルール

- 画面、データAPI、手動更新を含め、既存のBasic認証を適用する。
- 日本語表示、日本時間、HTTPS、検索エンジン非登録の既存ルールを引き継ぐ。
- 既存の白黒基調・マゼンタのアクセント、リーグロゴやチームエンブレムを表示しない方針を引き継ぐ。
- 主な利用端末はiPhone・iPad、次にPCとし、Firefoxの主要な最新バージョンで利用できるレイアウトにする。
- 画面操作と情報のまとめ方はJリーグ版に合わせる。NPB固有の順位項目、星取表、ポストシーズン情報を追加する。
- NPBのデータ・更新処理はJリーグのデータや自動更新処理から分離する。

## 5. URLと画面遷移

| URL | 内容 |
| --- | --- |
| `/` | スポーツポータルのトップページ |
| `/j-league/` | 既存のJリーグページ |
| `/npb/` | 2026年NPBページ |
| `/b-league/` | 「作成途中です」と表示する仮ページ |
| `/nba/` | 「作成途中です」と表示する仮ページ |

トップページのリンクは「Jリーグ → NPB → Bリーグ → NBA」の順に並べる。各ページからポータルトップへ戻れる既存の導線を維持する。

## 6. NPB試合ページ

### 6.1 画面上部

- 2026年シーズンを表示する。
- セ・リーグ／パ・リーグの切替タブは設けず、両リーグの試合を同じ画面に表示する（[#60](https://github.com/tj-999-comp/sport-portal/issues/60)）。
- 順位表モーダルを開くボタンを置く。
- 手動更新ボタン、最終更新日時、直近の更新成功／失敗状態を表示する。

日付ごとにセ・リーグ、パ・リーグの順で見出し付きの試合一覧を縦に並べる。試合がある区分のみ表示し、交流戦や日本シリーズ、リーグ共通のCS予定は専用の見出しにまとめて一度だけ表示する。

### 6.2 日付別試合一覧

- 試合開催日を列として横方向に並べ、過去を左、未来を右に配置する。
- 横方向の移動はタッチ操作で行えるようにする。
- 表示時は今日の日付を初期位置とし、今日の表示対象試合がない場合は次の開催日を初期位置にする。
- 各日には日付とその日に行われる試合を表示する。
- 同日・同区分内では開始時刻の早い試合から表示する。
- 表示対象期間は2026年公式戦およびCS・日本シリーズの日程を含む。

### 6.3 試合カード

各試合カードに以下を表示する。

- 開始予定時刻または公式発表の試合状態
- ホーム球団名とビジター球団名
- 試合終了後の最終スコア
- 必要に応じて球場名

開催前は予定時刻を、終了後は最終スコアを表示する。延期・中止・未開催などは公式発表の状態を表示し、未確定の結果を補完・推測しない。試合中の現在スコアは表示しない。

## 7. 順位表モーダル

「順位表」ボタンから開く。モーダル内に次のタブを設ける。

1. **順位表** — セ・リーグ／パ・リーグを見出し付きで縦に並べる。
2. **星取表** — セ・リーグ／パ・リーグを切り替える。
3. **クライマックスシリーズ** — セ・パ各ステージのトーナメントと試合結果。
4. **日本シリーズ** — トーナメントと試合結果。

### 7.1 順位表

各リーグの公式表示順に以下を表示する。

- 順位
- 球団名
- 試合数
- 勝利、敗北、引分
- 勝率
- ゲーム差

順位・数値・表示順はNPB公式発表に合わせる。規定や順位表で未確定の値は創作しない。

### 7.2 星取表

- 各リーグの球団同士の対戦成績を行列で表示する。
- ホーム・ビジターではなく球団間の通算成績として読み取れる形式にする。
- 公式データに勝・敗・分がある場合はその内訳を表示する。
- 交流戦成績は公式取得元で確認できる範囲で併記する。交流戦で対戦した全組み合わせを独自に補完しない。

### 7.3 クライマックスシリーズ

- セ・リーグ、パ・リーグそれぞれにファーストステージ、ファイナルステージを表示する。
- 各ステージは対戦トーナメントとして表示し、開催前の予定と開催後の各試合スコア・勝敗を区別する。
- 出場球団や試合結果が確定するまでは未確定として扱い、推測でチーム名や勝者を表示しない。
- 2026年のNPB公式ルールに基づき、ファーストステージとファイナルステージの勝ち上がり条件、アドバンテージを扱う。

2026年の公式告知では、ファーストステージは2位対3位の3試合制・先に2勝で勝者となる。ファイナルステージは通常6試合制・1位球団に1勝のアドバンテージを与え、アドバンテージを含め先に4勝で勝者となる。ただし、1位球団とファーストステージ勝者とのゲーム差が10以上、または同勝者のレギュラーシーズン勝率が5割未満の場合は、7試合制・1位球団に2勝のアドバンテージ・先に5勝で勝者となる。実際の表示はNPBの最新告知を基準とする。

### 7.4 日本シリーズ

- 対戦球団とシリーズの進行をトーナメント形式で表示する。
- 開催前の各試合予定、開催後の各試合の確定スコア・勝敗を表示する。
- 対戦球団や結果が未確定の段階で推測情報を表示しない。

## 8. データ取得・更新

### 8.1 取得元

NPB公式サイトを一次取得元とし、第三者サイトへ自動で切り替えない。

- [2026年度 セ・パ公式戦](https://npb.jp/games/2026/) と各月の「試合日程詳細」ページ — 日程・試合結果・状態
- [2026年度 セントラル・リーグ チーム勝敗表](https://npb.jp/bis/2026/stats/std_c.html) — セ・リーグ順位・対戦成績
- [2026年度 パシフィック・リーグ チーム勝敗表](https://npb.jp/bis/2026/stats/std_p.html) — パ・リーグ順位・対戦成績
- [2026年 セ・パ クライマックスシリーズについてのお知らせ](https://npb.jp/games/2026/info_cs.html) — 2026年CSの開催方式・公式ルール
- 日本シリーズの予定・結果 — NPB公式の日程・結果ページを取得元とする

2026年9月20日時点で調査した範囲では、上記情報を取得するための公開構造化APIは確認できなかった。実装時は公式ページの公開情報から取得する方法を再確認し、HTML抽出を行う場合は解析失敗を検出して不正なデータを保存しない。公式サイトの構成・取得条件が変わった場合は更新処理を見直す。チームロゴ・写真などの画像素材は取り込まない。

### 8.2 保存と失敗時の扱い

- 対象は2026年シーズンの最新状態とし、更新成功時に該当するNPBデータを置き換える。
- NPBデータの保存領域をJリーグ用と分離する。
- 取得に失敗した場合は前回正常に取得したデータを保持し、画面には更新失敗と失敗日時を表示する。
- 正常データが一度もない場合は「データを取得できていません」と表示する。
- 自動更新・手動更新の成功時は取得データと最終更新日時を反映する。

### 8.3 手動更新

- NPBページに手動更新ボタンを置く。
- 実行前にJリーグ版と同様の確認ダイアログを表示する。
- 更新中はボタンを無効にし、更新中であることを表示する。
- 更新完了後、試合・順位・星取表・ポストシーズンの取得内容と最終更新日時を反映する。
- 更新結果として成功／失敗状態と日時を表示する。

### 8.4 自動更新

- GitHub Actionsのスケジュール実行で毎日8回、NPB更新APIを呼び出す。
- 時刻は日本時間（JST）。GitHub Actionsに設定するUTC時刻はJSTから9時間を引いて指定する。
- Jリーグの既存ワークフロー・更新時刻・更新APIに変更を加えない。

| 日本時間（毎日） | UTC（毎日） |
| --- | --- |
| 15:00 | 06:00 |
| 17:00 | 08:00 |
| 18:00 | 09:00 |
| 19:00 | 10:00 |
| 20:00 | 11:00 |
| 21:00 | 12:00 |
| 22:00 | 13:00 |
| 23:00 | 14:00 |

## 9. 受け入れ条件

- Basic認証後、`/npb/` で2026年のセ・パ公式戦とポストシーズンの日程・確定結果を確認できる。
- 日付を横方向に移動して過去・未来の開催日を確認でき、初期位置は今日または次の開催日になる。
- セ・パの切替操作なしで同日の両リーグの試合を確認でき、一方のリーグのみの開催日や交流戦・ポストシーズンも欠落・重複なく表示される。
- 開催前の時刻、試合後の最終スコア、延期・中止等の公式状態を区別できる。
- 順位表モーダルの4タブ（順位表、星取表、CS、日本シリーズ）を切り替えられる。
- 順位表に順位、球団名、試合、勝、敗、分、勝率、ゲーム差が表示される。
- セ・パの星取表、CSの両ステージ、日本シリーズのトーナメントが確認できる。
- CS・日本シリーズの各試合について予定と確定結果を区別し、未確定情報を創作しない。
- 手動更新でNPBデータが更新され、最新更新日時と成功／失敗状態が確認できる。
- 自動更新は毎日15:00および17:00〜23:00 JSTの計8回に設定され、Jリーグの更新設定から独立している。
- 更新失敗時に前回正常データが保持される。
- トップページの順序がJリーグ、NPB、Bリーグ、NBAとなり、各導線が対応するページを開く。
- BリーグとNBAの遷移先には「作成途中です」と表示される。
- iPhone・iPad・PCのFirefoxで利用でき、HTTPS・Basic認証・検索エンジン非登録などの既存ルールを維持する。

## 11. 要件上の確認事項

- 2026年を初期対象シーズンとする。将来シーズンへの切り替え方法は別途検討する。
- 順位表・星取表・試合状態・CSルールの最終的な表記はNPB公式ページに合わせる。
- 公式サイトのHTMLやデータ提供方法が変わった場合は、実装時に取得方法を再確認する。
