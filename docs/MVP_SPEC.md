# スポーツポータル MVP 仕様書

## 1. 文書情報

- サイト名: スポーツポータル
- 対象シーズン: 2026年J1リーグ（年初に設定値を手動変更）
- 初版作成日: 2026-09-07
- MVPの目的: J1リーグの試合予定・最終結果・順位表を、本人がスマートフォンやiPadから確認できるようにする

## 2. MVPの範囲

### 対象機能

1. J1リーグの試合予定の表示
2. J1リーグの試合結果の表示
3. J1リーグの順位表の表示
4. 公式サイトからのデータ取得・更新
5. 手動更新
6. 最新更新日時と更新結果の表示
7. Basic認証によるアクセス制限

### 対象外

- J2・J3、Bリーグ、海外リーグ、プロ野球などの表示（将来拡張を想定した内部設計のみ行う）
- 試合中の速報、現在スコア、得点イベント、退場などのライブ情報
- 選手情報
- 試合詳細ページ、公式サイトへのリンク
- 検索、チーム絞り込み、日付フィルター
- 順位変動、勝敗推移などの履歴情報
- 利用者登録、データ登録、管理画面、設定画面
- アクセス解析、通知、PWA、オフライン対応

## 3. 利用者・認証

- 利用者は本人のみ。
- 画面、データ取得API、手動更新処理を含む全URLにBasic認証を適用する。
- 認証情報はCloudflare WorkersのSecretに保存する。
- ユーザー名・パスワードは利用者が決定し、実装時に設定する。

## 4. 対応環境・デザイン

- 主な利用端末: iPhone・iPad 80%、PC 20%
- 対応ブラウザ: iPhone・iPad・PCのFirefox（主要な最新バージョン）
- 表示言語: 日本語のみ
- 時刻・日付: 日本時間
- デザイン: 白黒を基調とし、アクセントカラーにマゼンタを使用
- チームエンブレムやリーグロゴは表示しない
- サイトはHTTPSで提供する。
- 検索エンジンには登録させない（`noindex`、`robots.txt`などを設定する）。

## 5. 画面仕様

### 5.1 トップ画面

トップ画面には以下を表示する。

- サイト名「スポーツポータル」
- 対象シーズン
- 最新更新日時
- 手動更新ボタン
- J1リーグの試合一覧
- 順位表を開くボタン
- 更新成功・更新失敗の状態

MVPではトップページ1ページ構成とし、管理画面や設定画面は作成しない。

### 5.2 試合一覧

- 試合開催日を1列として、横方向に並べる。
- 試合がある日だけ列を作成し、試合のない日は表示しない。
- 左方向に過去、右方向に未来の開催日を配置する。
- ページ表示時は今日の列を初期位置とする。
- 今日に試合がない場合は、次に試合がある開催日を初期位置とする。
- 横スクロールはスワイプで操作できるようにする。
- 各列には、節、開催日、その日の試合を表示する。
- 同じ開催日の試合はキックオフ時刻の早い順に並べる。
- 節の表示は公式サイトの表記に合わせる。延期などで同一節の開催日が分かれる場合も、公式サイトの情報を優先する。

### 5.3 試合カード

各試合カードには以下を表示する。

- キックオフ時刻または試合状態
- ホームチーム名（上段）
- アウェイチーム名（下段）
- 試合終了後の最終スコア

チーム名は公式サイトの省略名を使用する。

- 開催前: キックオフ時刻を表示する。
- 終了後: 最終スコアを表示する。
- 延期・中止・未開催: スコアの代わりに公式サイトの状態を表示する。
- 試合中の速報や現在スコアは表示しない。

### 5.4 順位表モーダル

ボタン操作で順位表をモーダル表示する。スマートフォン・iPadで横スクロールせず確認できるよう、画面幅に合わせてレイアウトを調整する。

表示項目:

- 順位
- チーム名
- 試合数
- 勝利
- 引き分け
- 敗戦
- 得点
- 失点
- 得失点差
- 勝点

公式サイトの表示順・数値・順位決定方法に合わせる。前節からの順位変動や履歴は表示しない。

## 6. データ取得・更新

### 6.1 データ源

- Jリーグ公式サイトの公開ページをデータ源とする。
- 試合情報は公式のJ1日程・結果ページ、順位表は公式のJ1順位表ページを候補とし、実装時に取得元URLを確定する。
- 公式サイトのHTMLを読み取り、必要な項目を抽出する。
- 公式サイトのページ構成変更により取得処理の修正が必要になる場合がある。

### 6.2 自動更新

- Cloudflare Workersの定期実行を利用する。
- 毎日5回、自動更新する。
- 自動更新の具体的な5時刻は `DEPLOYMENT.md` に定める。
- 時刻は日本時間で設計し、Cloudflare WorkersのUTC設定へ変換する。
- 試合の有無にかかわらず、毎日同じ回数で更新する。

### 6.3 手動更新

- トップ画面の手動更新ボタンから、試合予定・試合結果・順位表をすべて再取得する。
- 実行前に確認ダイアログを表示する。
- 更新中はボタンを無効化し、「更新中」と表示する。
- 自動更新と手動更新は独立して実行できる。
- 更新完了後、取得データと最新更新日時を画面へ反映する。
- 更新結果として、更新成功または更新失敗と更新日時を表示する。取得試合数は表示しない。

### 6.4 保存・失敗時の挙動

- 現在シーズンの最新データのみ保存し、更新時に上書きする。
- 更新履歴や過去時点の順位表は保存しない。
- 公式サイトから取得できない場合は、他のデータ源へ切り替えない。
- 更新に失敗した場合は、前回正常に取得したデータを表示する。
- 画面には更新失敗状態と失敗日時を表示する。
- 初回取得前など表示可能なデータがない場合は、「データを取得できていません」と表示する。
- 公式サイトから取得できたデータに数時間の遅延があっても、取得処理が成功していれば許容する。

## 7. Cloudflare構成

- 静的な画面: Cloudflare Pages
- データ取得、API、定期実行、手動更新: Cloudflare Workers
- 無料枠を前提とする。
- 独自ドメインは使用せず、初期公開はCloudflare Pagesの`pages.dev`ドメインとする。
- 将来のリーグ追加に対応しやすいデータ構造・取得処理とする。ただし、MVPで表示するリーグはJ1のみとする。

## 8. 受け入れ条件

- Basic認証を通過した利用者が、J1の2026年シーズンの試合予定・試合結果・順位表を閲覧できる。
- 初期表示位置が今日、または次の試合開催日になっている。
- 開催日ごとの横スクロールで過去・未来の全試合を確認できる。
- 節、開催日、時刻、ホーム・アウェイ、省略チーム名、最終スコアを確認できる。
- 延期・中止・未開催の状態を確認できる。
- 順位表モーダルで指定した10項目を確認できる。
- 手動更新で3種類のデータ（試合予定、試合結果、順位表）を再取得できる。
- 自動更新が毎日5回実行される。
- 最新更新日時と更新結果を確認できる。
- 更新失敗時に前回データが保持され、失敗状態が表示される。
- iPhone・iPad・PCのFirefoxで利用できる。
- HTTPS、全URLのBasic認証、検索エンジン非登録が有効になっている。
