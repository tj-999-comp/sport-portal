# ポータル構成

更新日: 2026-09-08

## URL構成

| URL | 役割 | 状態 |
| --- | --- | --- |
| `/` | リーグを選択するポータルトップ | STGで先行反映 |
| `/j-league/` | 2026年J1の試合・順位表 | 既存画面を移設 |
| `/design-review.html` | デザイン提案の比較・採用理由の記録 | STG専用 |

## 方針

- ルートは特定リーグの画面ではなく、リーグ選択の入口とする。
- リーグごとの画面は `/[league-slug]/` 配下へ追加する。
- リーグ画面からポータルトップへ戻れる導線を持つ。
- デザインレビューは運用確認用ページとして、検索インデックス対象外とする。
- STGでURL、リンク、認証、データ取得を確認した後、明示的な承認を得て本番へ反映する。

## 互換性と移行

今回の変更では、従来ルートにあったJ1画面を `/j-league/` へ移した。Productionのルート変更は、STG受入と本番反映承認が完了するまで行わない。

将来リーグを追加する場合は、ポータルトップのリーグカード、配下URL、データ取得対象、受入テストを同じ変更単位で追加する。
