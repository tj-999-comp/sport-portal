# 2026-27 NBAページ要件

## 対象

- `/nba/` に2026-27シーズンのプレシーズンからNBA Finalsまでの日程・結果を表示する。
- 過去シーズン選択と次シーズンへの自動切替は対象外。
- 日時はJST、チーム名は正式英語名で表示する。試合中の途中スコアは表示しない。
- 日付チップは試合のある日だけを過去から未来へ並べ、今日、次の開催日、最後の開催日の順で初期選択する。日付ボタンと横スワイプで切り替える。

## 順位・大会情報

- 下部シートに「順位表」「NBA Cup」「Play-In」「プレーオフ」の4タブを置く。
- 順位表は東西のConferenceを縦に置き、Rank、Team、W、L、WIN%、GB、CONF、HOME、ROAD、LAST 10、STREAK、進出状況を表示する。Division表は作らない。
- NBA Cupはグループ順位・進出状況・ノックアウトを表示する。Play-Inとプレーオフは確定した対戦・予定・結果だけを表示する。
- 未取得、未発表、取得失敗を分ける。順位などから対戦や進出を推定しない。
- モーダルはEscape、背景、閉じるボタンで閉じられ、フォーカスを開いたボタンへ戻す。

## データ提供元と環境

2026年9月30日の依頼に基づき、第三者データ提供元を候補に含め、API-Sportsを認証付きSTGで技術評価する。キーはSTG Worker Secret `NBA_API_KEY` に置き、ブラウザやGitHub Actionsへ複製しない。

API-Sportsの公開ガイドはNBA `/games` と `/standings` を案内する一方、試合 `stage` の例は数値で、大会区分との対応は確認できていない。未検証のstageは大会区分へ読み替えず「大会区分未取得」として表示する。公開ガイドからNBA Cupのグループ表・進出情報やPlay-In／プレーオフのブラケットを確認できていないため、対応確認までは提供元から未取得と表示する。

API-Sportsの利用規約は第三者データの掲載許諾を同社が付与しない旨を記載している。公開利用に必要な許諾が確認されるまでAPI-SportsデータをProductionへ出さない。本番反映も利用者の明示承認が必要。

## 更新・保全

- NBA専用KVキー `nba-2026-27` と `/api/nba/data`, `/api/nba/status`, `/api/nba/update` を使い、他競技のデータと分ける。
- APIアクセスはBasic認証で保護する。同時更新は一つにまとめ、取得・検証・保存に失敗した場合は前回データを保つ。
- 自動更新Workflowは毎日8、10、12、14、16時JSTに実行する。Cloudflare Worker Cronは使わない。
- STG受入が終わるまで本番へ反映しない。

GitHub ActionsのScheduleとWorkflow Dispatchはデフォルトブランチ上のファイルが必要なため、`stg` ブランチにある現行Workflowはまだ起動できない。デフォルトブランチの更新はSTG受入まで保留する。
